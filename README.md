Metatron-Remix: (Re)mix Your Own Style

Elevate your Linux Mint desktop with Metatron-Remix, a comprehensive theme overhaul designed specifically for the Cinnamon desktop environment. Building upon the classic Metatron design, this remix brings deep customization and a modern, cohesive aesthetic to your workspace.

This theme was developed for Linux Mint 22 "Zena". If you are using a different version, please ensure that the Yaru icon themes and the DMZ cursor themes are installed so that the theme works correctly.

This theme is based on Mint-Y-Themes and Zorin-Desktop-Themes.
